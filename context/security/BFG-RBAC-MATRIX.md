# BFG RBAC MATRIX

Status: `GREEN_EVIDENCE` / `REMEDIATED_GREEN` · reviewed 2026-08-22.
Authorization is evaluated on the Convex server; UI visibility is not part of
the decision.

## Role and Status Model

| Dimension | Canonical values                                                                         | Enforcement                                        |
| --------- | ---------------------------------------------------------------------------------------- | -------------------------------------------------- |
| Role      | `owner`, `admin`, `customer`                                                             | `convex/lib/auth.ts` permission sets               |
| Status    | `active`, `suspended` (plus schema-defined invitation/request states outside `appUsers`) | `requireActiveUser` before permission or ownership |
| Identity  | Clerk `identity.subject` → `appUsers.clerkUserId`                                        | `requireIdentity` + indexed current-user lookup    |

## Owner-Only Actions

`users.inviteStaff`, `users.revokeStaffInvitation`, `users.updateRole`,
`users.suspend`, `users.reactivate`, `settings.update`, and audit/user
management queries require `requireOwner`. There is no domain/email suffix,
hardcoded Gmail, hardcoded current-user ID, or client-provided role shortcut.
The configured Owner Clerk subject is read only from server environment.

## Status Rule

Suspension is checked before permission evaluation. A suspended Clerk session
may still exist at the provider, but it cannot use protected BFG queries or
mutations. Public content and the intentionally public Ready Stock projection
remain public; that is not private customer access.
