## Client-Invokable but Not Authority

- Route guards, hidden navigation, disabled buttons, `sessionStorage`, public
  references, `userId` arguments, `role` fields, email addresses, and
  catalog UI state are all untrusted.
- The public Catalog gateway is intentionally client-invokable, but it can
  only return the scoped catalog projection after server validation.
- `readyStock.list/getBySlug` are intentionally public, but only expose the
  published positive-stock projection.

## Query / Scale Review

- Public Ready Stock is capped at 200 books and returns at most 100 filtered
  items; publishers and catalog reads use pagination or operational caps.
- Payment/deposit/activity/customer reads use ownership indexes and bounded
  pagination.
- Bulk import and several Admin projections have explicit row/table caps; the
  remaining ceiling is a documented scale concern, not a client authorization
  shortcut.
- No app-level rate-limit mutation is attached to ordinary reactive queries;
  the rate-limit matrix covers only abuse-sensitive state changes and the
  public code gateway.
