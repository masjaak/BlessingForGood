## Form verdict

Join, catalog access/order, profile, addresses, payment confirmation, Book
Master, catalogs, assisted orders, batches, admissions, payments, invoices, and
exceptions retain labels, native/server validation, pending/disabled behavior,
and safe success/error feedback. No decorative primary button was found.
