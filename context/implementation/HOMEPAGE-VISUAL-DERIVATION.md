# Homepage Visual Derivation V4.1.2

The homepage has no direct reference image. It is designed as a hypothetical
`mockup 0.png` using the recurring rules visible in mockups 1-8. V4.1.2
supersedes the earlier four-action/quick-path composition with a clearer
product journey.

## Superseded composition

The old hero buttons plus loose `Gabung Blessfriends` / `Cara memesan` links,
followed by the three Quick Paths cards, made four different jobs look equal.
V4.1.2 removes that cluster from the homepage. The routes remain unchanged;
each action now belongs to its role:

1. Ready Stock — primary discovery.
2. Secret Catalog — secondary/private discovery.
3. Gabung Blessfriends — community conversion banner.
4. Lihat cara memesan — educational content preview conclusion.

The homepage keeps its approved content and destinations. Only composition,
spacing, typography, surfaces, and responsive behavior are translated.
