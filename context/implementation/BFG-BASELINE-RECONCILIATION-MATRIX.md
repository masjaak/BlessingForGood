## Classification Rules

- `SYNCED` means source, reachable route/UI, backend consequence, state,
  authorization, tests, and available Production evidence agree.
- `PARTIAL` means the active contract has a real implementation but one
  required layer or sub-capability remains bounded; it must have a named fix or
  candidate rather than a vague completion claim.
- `DEFERRED` means source-supported but intentionally not implemented in this
  baseline; it is listed in the Phase 08/future contract.
- `EXCLUDED` means the current source contract explicitly forbids it.
- No row uses “probably fine”, “mostly implemented”, or “seems complete”.
