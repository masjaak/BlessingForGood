# Repository blueprint

This package contains the approved documentation pack and the Phase 01 foundation. Business features, schema, production integrations, and final visual implementation remain deferred.

Codex Phase 01 determines exact framework/version and creates package/config/source files only after validating current official provider compatibility.

Primary folders:

- `context/` source of truth
- `prompts/` phase instructions
- `public/` expected approved assets and mockups
- `src/` frontend boundaries
- `convex/` backend boundaries
- `tests/` test boundaries
- `scripts/` guarded operational scripts
- `infrastructure/` deployment configuration records
